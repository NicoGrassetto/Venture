# Quantify the Value Proposition: Method Reference

Use this reference when the core workflow requires deeper analysis. Keep the final artifact concise and move raw evidence to linked notes or data files.

## Decision objective

A customer-verifiable, one-page value case with an explicit baseline, measurable change, calculation, evidence, and sensitivity range.

## Method notes

- Common value forms include time saved x loaded cost, incremental volume x contribution, avoided incidents x expected loss, or reduced cycle time x economic effect.
- Discount claimed value for adoption, utilization, realization delay, and the portion attributable to the product.
- Prefer a simple calculation that customers can audit over a comprehensive model they cannot explain.

## Review questions

- Can the team demonstrate: the metric matches the persona's first purchasing priority.
- Can the team demonstrate: the baseline and future state use the same units and horizon.
- Can the team demonstrate: all material assumptions are visible and sensitivity-tested.
- Can the team demonstrate: a customer recognizes the baseline and accepts the logic, even if inputs remain ranges.

Also ask:

- What observation would make the current conclusion wrong?
- Which input has the greatest leverage on the decision?
- Is the evidence from the actual beachhead and actual decision makers?
- Have incentives, selection bias, and survivorship bias been considered?
- Is the next action the cheapest action that can materially reduce uncertainty?
