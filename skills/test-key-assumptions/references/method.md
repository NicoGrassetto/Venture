# Test Key Assumptions: Method Reference

Use this reference when the core workflow requires deeper analysis. Keep the final artifact concise and move raw evidence to linked notes or data files.

## Decision objective

Decision-grade experiment results that update confidence and trigger a clear proceed, revise, pivot, or stop action.

## Method notes

- Use an evidence ladder: opinion < stated preference < demonstrated effort < commitment < payment < sustained use.
- Match experiment strength to decision cost; irreversible or expensive decisions require stronger evidence.
- Pre-register the decision rule in the workbook and time-stamp changes if the design must change.

## Review questions

- Can the team demonstrate: the threshold and decision rule are set before observing results.
- Can the team demonstrate: the measured behavior is meaningfully connected to the assumption.
- Can the team demonstrate: results include failures, drop-offs, and contradictory evidence.
- Can the team demonstrate: the decision follows the evidence rather than post-hoc rationalization.

Also ask:

- What observation would make the current conclusion wrong?
- Which input has the greatest leverage on the decision?
- Is the evidence from the actual beachhead and actual decision makers?
- Have incentives, selection bias, and survivorship bias been considered?
- Is the next action the cheapest action that can materially reduce uncertainty?
