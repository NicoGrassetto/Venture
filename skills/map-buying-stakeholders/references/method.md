# Map Buying Stakeholders: Method Reference

Use this reference when the core workflow requires deeper analysis. Keep the final artifact concise and move raw evidence to linked notes or data files.

## Decision objective

A role-based, named DMU map showing each stakeholder's criteria, influence, evidence needs, objections, and relationships.

## Method notes

- Use role definitions based on behavior: champion actively drives adoption; economic buyer controls budget; veto holder can stop the deal.
- Map what each role gains and risks personally as well as organizationally.
- Repeat the exercise across accounts to distinguish a repeatable DMU pattern from one company's structure.

## Review questions

- Can the team demonstrate: champion and primary economic buyer are identified separately unless evidence proves they are the same.
- Can the team demonstrate: potential veto holders are explicit.
- Can the team demonstrate: each stakeholder has role-specific success criteria and proof needs.
- Can the team demonstrate: the map is based on actual purchasing behavior, not only an org chart.

Also ask:

- What observation would make the current conclusion wrong?
- Which input has the greatest leverage on the decision?
- Is the evidence from the actual beachhead and actual decision makers?
- Have incentives, selection bias, and survivorship bias been considered?
- Is the next action the cheapest action that can materially reduce uncertainty?
