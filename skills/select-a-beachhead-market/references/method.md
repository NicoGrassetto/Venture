# Select a Beachhead Market: Method Reference

Use this reference when the core workflow requires deeper analysis. Keep the final artifact concise and move raw evidence to linked notes or data files.

## Decision objective

One explicitly chosen, homogeneous beachhead market with a documented rationale, exclusions, and remaining segmentation risks.

## Method notes

- Use scores to expose assumptions, not to manufacture precision. Add an evidence-strength column beside every score.
- A usable beachhead usually allows one product, one core value proposition, and one repeatable acquisition motion.
- If two subgroups use different purchasing criteria or cannot refer each other, split them even if analysts place them in the same industry.

## Review questions

- Can the team demonstrate: exactly one market is selected for current execution.
- Can the team demonstrate: the market definition specifies end user, application, context, and geography where relevant.
- Can the team demonstrate: customers can plausibly create word of mouth within the market.
- Can the team demonstrate: the team can reach enough customers to learn and sell without building several products.

Also ask:

- What observation would make the current conclusion wrong?
- Which input has the greatest leverage on the decision?
- Is the evidence from the actual beachhead and actual decision makers?
- Have incentives, selection bias, and survivorship bias been considered?
- Is the next action the cheapest action that can materially reduce uncertainty?
