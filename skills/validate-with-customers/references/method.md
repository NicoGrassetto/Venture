# Validate with Customers: Method Reference

Use this reference when the core workflow requires deeper analysis. Keep the final artifact concise and move raw evidence to linked notes or data files.

## Decision objective

A named pipeline of representative customers and a cross-customer evidence synthesis that confirms, revises, or rejects prior assumptions.

## Method notes

- Use a matrix with customers as rows and critical assumptions as columns to reveal consistency and contradiction.
- Weight observed behavior and concrete commitments above compliments or hypothetical intent.
- When evidence splits into distinct clusters, investigate whether the beachhead contains multiple segments.

## Review questions

- Can the team demonstrate: actual qualified-customer observations support the cross-customer synthesis, with a justified target sample and an inconclusive decision if the target is not met.
- Can the team demonstrate: evidence is compared across customers using consistent fields.
- Can the team demonstrate: negative feedback changes analysis rather than being dismissed.
- Can the team demonstrate: the decision states what evidence would reverse it.

Also ask:

- What observation would make the current conclusion wrong?
- Which input has the greatest leverage on the decision?
- Is the evidence from the actual beachhead and actual decision makers?
- Have incentives, selection bias, and survivorship bias been considered?
- Is the next action the cheapest action that can materially reduce uncertainty?
