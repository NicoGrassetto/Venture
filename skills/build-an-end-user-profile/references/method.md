# Build an End-user Profile: Method Reference

Use this reference when the core workflow requires deeper analysis. Keep the final artifact concise and move raw evidence to linked notes or data files.

## Decision objective

A research-backed end-user profile that makes the beachhead concrete and guides recruiting, product decisions, and later persona selection.

## Method notes

- For each attribute, complete the sentence: 'This matters because it changes ...'. Remove attributes with no credible consequence.
- Use ranges, clusters, and qualifying conditions instead of an unsupported single average.
- Keep organization-level firmographics separate unless they directly constrain the end user's context.

## Review questions

- Can the team demonstrate: every retained attribute has a stated decision consequence.
- Can the team demonstrate: the profile describes users, not the organization buying the product.
- Can the team demonstrate: recruiting criteria can identify matching users consistently.
- Can the team demonstrate: the profile is broad enough to contain a market but specific enough to guide product choices.

Also ask:

- What observation would make the current conclusion wrong?
- Which input has the greatest leverage on the decision?
- Is the evidence from the actual beachhead and actual decision makers?
- Have incentives, selection bias, and survivorship bias been considered?
- Is the next action the cheapest action that can materially reduce uncertainty?
