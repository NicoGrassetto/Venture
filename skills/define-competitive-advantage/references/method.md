# Define Competitive Advantage: Method Reference

Use this reference when the core workflow requires deeper analysis. Keep the final artifact concise and move raw evidence to linked notes or data files.

## Decision objective

A concise core statement supported by customer relevance, capability evidence, defensibility mechanisms, and a plan to compound it.

## Method notes

- Use a capability chain: resources -> repeatable activity -> customer outcome -> reinforcement loop.
- Ask how the advantage improves with each customer, transaction, dataset, employee, or cycle of learning.
- Reject candidates that depend mainly on secrecy, temporary access, or competitors failing to respond.

## Review questions

- Can the team demonstrate: the core directly improves a customer priority.
- Can the team demonstrate: competitors cannot reproduce it quickly by copying a feature.
- Can the team demonstrate: the venture can invest in and measure its strengthening over time.
- Can the team demonstrate: the statement is narrow enough to guide resource allocation.

Also ask:

- What observation would make the current conclusion wrong?
- Which input has the greatest leverage on the decision?
- Is the evidence from the actual beachhead and actual decision makers?
- Have incentives, selection bias, and survivorship bias been considered?
- Is the next action the cheapest action that can materially reduce uncertainty?
